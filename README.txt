USERNAME BOT v2

Что изменилось:
- Используется Telegram MTProto account.checkUsername.
- Занятые username сохраняются в occupied_usernames.txt.
- При следующих поисках username из occupied_usernames.txt вообще не
  генерируются/не проверяются повторно.
- Кандидаты сортируются по рейтингу до проверки Telegram.
- USERNAME_PURCHASE_AVAILABLE отделён от обычных занятых.
- Генератор создаёт более читаемые 5-буквенные варианты.

Установка:
    python -m pip install -r requirements.txt

Запуск:
    python bot.py

Нужны:
- BOT_TOKEN от @BotFather
- API_ID
- API_HASH
- Telegram user session

ВАЖНО:
account.checkUsername предназначен для проверки username текущим
пользовательским аккаунтом. Telegram может применять FloodWait. Код не
обходит ограничения Telegram через дополнительные аккаунты или прокси.

occupied_usernames.txt — постоянный архив занятых имён. Если имя позже
освободится, оно всё равно останется в этом архиве и бот специально не
будет возвращаться к нему. Для будущего "отслеживания освобождённых"
используй отдельную систему ловушек, а не этот архив.


НОВЫЙ АРХИВ СВОБОДНЫХ:
- free_usernames.txt хранит каждый username, который Telegram подтвердил как свободный.
- Повторно найденные имена не дублируются.
- Кнопка "📚 Все свободные за всё время" показывает накопленный архив.
- Архив свободных НЕ означает, что имя остаётся свободным навсегда: username
  может занять другой пользователь после проверки.
- occupied_usernames.txt остаётся отдельным постоянным архивом занятых.
